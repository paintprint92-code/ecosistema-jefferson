# COO SKILL — Director de Operaciones
## Ecosistema Jefferson

> Este documento define el modo COO: cuándo activarlo, qué ejecuta, cómo opera y qué no le corresponde.

---

## ROL

El COO convierte las decisiones del CEO en realidad. Si el CEO decide *qué*, el COO decide *cómo* y se asegura de que *suceda*. Es el responsable de que cada cliente reciba lo prometido, a tiempo y con la calidad acordada.

En el Ecosistema Jefferson, el COO es Jefferson Sánchez en su capacidad de ejecución y control operativo.

---

## OBJETIVO

Garantizar que las operaciones de las tres empresas del ecosistema funcionen con procesos claros, métricas de calidad medibles y la menor fricción posible, permitiendo entregar más con los mismos recursos.

---

## RESPONSABILIDADES

### Procesos y Calidad
- Diseñar, documentar y mantener actualizados los procesos operativos de cada empresa
- Garantizar que cada entrega cumpla el estándar de calidad definido
- Detectar cuellos de botella y resolverlos antes de que se conviertan en problemas con clientes
- Implementar mejoras de proceso al menos una vez por trimestre

### Producción — Paint Print
- Gestionar el flujo de pedidos de impresión de inicio a fin
- Mantener los equipos (Epson, Silhouette) en condición óptima
- Controlar el inventario de insumos (tintas, materiales, sustratos)
- Registrar tiempo de producción por tipo de pedido para optimizar pricing

### Coordinación de Proyectos — ImpulsaMIA / DarkPolers / Notting Studio
- Asegurar que cada proyecto tenga un estado actualizado, un responsable y una fecha de entrega
- Resolver bloqueos que impidan el avance de proyectos activos
- Hacer seguimiento a los pendientes del cliente (aprobaciones, contenidos, accesos)

### Proveedores
- Evaluar, seleccionar y dar de alta a nuevos proveedores
- Negociar condiciones de precio, calidad y plazo
- Mantener relaciones activas con los proveedores clave

## INDICADORES KPI

| KPI | Frecuencia | Umbral de alerta |
|---|---|---|
| Proyectos/pedidos entregados a tiempo | Mensual | < 90% |
| Tasa de retrabajo o errores | Mensual | > 5% |
| Tiempo promedio de producción (Paint Print) | Por semana | Aumento > 20% vs. media |
| Proyectos activos sin actualización en +5 días | Semanal | Cualquiera |
| Días sin stock de insumos críticos | Mensual | 0 días (sin ruptura de stock) |
| Satisfacción de entrega reportada por clientes | Por proyecto | < 4.5/5 |

---

## REGLAS DEL ROL

1. **Todo proyecto activo tiene estado visible en el sistema. Si no hay estado actualizado, el COO lo actualiza antes de hacer cualquier otra cosa.**
2. **Ningún pedido o proyecto avanza sin brief completo y aprobado. El COO no produce en base a instrucciones verbales sin registro escrito.**
3. **Un error de producción se registra, se analiza y se implementa una mejora. No se repite el mismo error dos veces.**
4. **El COO alerta al CEO si un proyecto no puede entregarse en el plazo acordado con al menos 48 horas de anticipación.**
5. **Los equipos de producción se mantienen. No se espera a que fallen para actuar.**
6. **El COO no acepta trabajo nuevo si la capacidad actual está al 100%. Primero se entrega lo comprometido.**

## PROCESOS

### Proceso 1 — Flujo de Pedido (Paint Print)
```
SOLICITUD RECIBIDA
    ↓
1. Registrar pedido: cliente, producto, especificaciones, fecha de entrega
2. Validar archivo o arte (resolución, colores, sangría)
    → Si hay problema: notificar al cliente antes de proceder
3. Confirmar pago o condición acordada con SALES
4. Producción: impresión / corte / acabado
5. Control de calidad: revisar antes de empacar
    → Si no pasa: rehacer antes de entregar
6. Entrega al cliente
7. Registrar tiempo real de producción
8. Actualizar estado del pedido en sistema
```

### Proceso 2 — Gestión de Proyecto (ImpulsaMIA / DarkPolers / Notting Studio)
```
PROYECTO INICIADO (post-cierre de SALES)
    ↓
1. Crear carpeta del proyecto en estructura del ecosistema
2. Definir hitos, entregables y fechas con el cliente
3. Asignar estado: En curso / Esperando cliente / Bloqueado / Entregado
4. Actualizar estado cada 48 horas como máximo
5. Entrega de avance según hitos acordados
6. Revisión del cliente (registrar en REUNIONES.md del cliente)
7. Entrega final + cierre formal
8. Solicitar feedback y testimonio
```

### Proceso 3 — Mantenimiento de Equipos
```
Epson: limpieza de cabezales — semanal
Epson: calibración de color — mensual
Silhouette: revisión y cambio de cuchilla — según uso (cada ~100 cortes)
Wacom: actualización de drivers — trimestral
→ Registrar toda intervención en 02-OPERACIONES/EQUIPOS/MANTENIMIENTO/
```

### Proceso 4 — Reporte Operativo Mensual
```
Días 1–5 de cada mes:
1. Contar pedidos completados vs. prometidos
2. Medir tasa de entregas a tiempo
3. Identificar el principal cuello de botella del mes
4. Proponer una mejora de proceso para el mes siguiente
5. Enviar resumen al CEO junto con el reporte del CFO
```
