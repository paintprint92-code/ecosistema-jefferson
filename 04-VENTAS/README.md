# 04 — VENTAS

> Pipeline comercial, cierre de negocios y relación con clientes del ecosistema.

## Propósito

Convertir prospectos en clientes y clientes en compradores recurrentes, gestionando el pipeline de ventas de forma ordenada y medible para cada empresa del ecosistema.

## Responsables

| Rol | Nombre |
|---|---|
| Director Comercial | Jefferson (actual) |
| Asesor de ventas | (por definir) |

## Funciones Clave

- Gestión del pipeline de ventas (prospecto → cliente → recurrente)
- Elaboración y seguimiento de cotizaciones
- Negociación y cierre de contratos
- Onboarding de nuevos clientes
- Seguimiento post-venta y fidelización
- Detección de oportunidades de upsell y cross-sell
- Reporte mensual de ventas a Dirección General

## Indicadores (KPIs)

| Indicador | Frecuencia | Meta |
|---|---|---|
| Nuevos clientes por mes | Mensual | ≥ 5 |
| Tasa de cierre (cotización → venta) | Mensual | ≥ 30% |
| Ticket promedio por empresa | Mensual | Crecimiento 10% anual |
| Tasa de retención de clientes | Trimestral | ≥ 80% |
| Revenue por cliente (LTV) | Semestral | Incremento constante |

## Procesos

### Pipeline de Ventas

```
PROSPECTO → CONTACTO → COTIZACIÓN → NEGOCIACIÓN → CIERRE → ONBOARDING
```

| Etapa | Acción clave | Tiempo máximo |
|---|---|---|
| Prospecto | Registrar en CRM | Inmediato |
| Contacto | Llamada o mensaje inicial | 24 horas |
| Cotización | Enviar propuesta | 48 horas |
| Negociación | Responder objeciones | 72 horas |
| Cierre | Confirmar pago o contrato | — |
| Onboarding | Bienvenida y briefing | 48 hs post-cierre |

### Elaboración de Cotización
1. Entender el requerimiento completo del cliente
2. Calcular costos de producción + margen
3. Preparar propuesta en plantilla oficial
4. Enviar con validez de 7 días
5. Hacer seguimiento a las 48 horas si no hay respuesta

### Seguimiento Post-Venta
- Encuesta de satisfacción al finalizar el trabajo
- Check-in a los 30 días
- Oferta de recompra o servicio complementario a los 60 días
