## Procesos Clave

### Proceso de Branding
```
DISCOVERY → INVESTIGACIÓN → CONCEPTO → DISEÑO → REVISIÓN → ENTREGA → BRANDBOOK
```

1. **Discovery:** Brief, objetivos, audiencia, competencia, referencias
2. **Investigación:** Análisis de mercado y posicionamiento
3. **Concepto:** 2-3 direcciones creativas para elección
4. **Diseño:** Desarrollo de la dirección elegida
5. **Revisión:** 2 rondas de ajustes incluidas
6. **Entrega:** Archivos maestros + guía de uso
7. **Brandbook:** Manual de identidad completo
