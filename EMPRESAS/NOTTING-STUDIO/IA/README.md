# IA — Notting Studio

> Consultoría e implementación de Inteligencia Artificial para negocios que quieren operar más inteligente.

## Propósito

Ayudar a emprendedores y empresas a integrar herramientas de IA de forma práctica: desde automatizar respuestas hasta construir agentes que trabajen de forma autónoma dentro de su negocio.

## Servicios de IA

| Servicio | Descripción | Tiempo estimado |
|---|---|---|
| Auditoría de IA | Qué procesos del negocio pueden automatizarse con IA | 1–2 días |
| Implementación de agentes | Agentes Claude/GPT para atención, ventas o análisis | 5–15 días |
| Prompts de negocio | Sistema de prompts personalizados para el cliente | 3–5 días |
| Integración de IA en web | Chatbots, asistentes, formularios inteligentes | 5–10 días |
| Capacitación en IA | Taller práctico para el equipo del cliente | 1 día |
| Consultoría estratégica de IA | Hoja de ruta de IA para el negocio | 2–3 días |

## Herramientas y Stack

| Herramienta | Uso |
|---|---|
| Claude (Anthropic) | Agentes, análisis, estrategia |
| ChatGPT / GPT-4o | Generación de contenido y asistencia |
| Make / n8n | Orquestación de flujos con IA |
| Anthropic API | Agentes personalizados para clientes |
| Perplexity / Claude | Investigación y análisis de mercado |

## Tipos de Proyectos de IA

### Para Clientes de Marketing / Agencias
- Generación automática de calendarios de contenido
- Redacción de copies publicitarios con IA
- Análisis de competencia automatizado

### Para Negocios de Servicio
- Chatbot de atención inicial (WhatsApp / web)
- Agente de cotización automática
- Resumen y análisis de feedback de clientes

### Para Operaciones
- Automatización de reportes
- Clasificación y respuesta de correos
- Extracción de datos de documentos

## Proceso de Proyecto de IA

```
DIAGNÓSTICO → DISEÑO DE SOLUCIÓN → PROTOTIPO → PRUEBAS → IMPLEMENTACIÓN → CAPACITACIÓN
```

1. **Diagnóstico:** Entender el proceso actual, el dolor y el objetivo
2. **Diseño:** Arquitectura de la solución IA
3. **Prototipo:** Versión funcional mínima para validar
4. **Pruebas:** Iteración con el cliente
5. **Implementación:** Deploy en el entorno del cliente
6. **Capacitación:** El cliente aprende a usar y mantener la solución
