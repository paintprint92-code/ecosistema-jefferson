# Web Design — Notting Studio

> Diseño y desarrollo de sitios web que combinan estética profesional con rendimiento técnico y conversión real.

## Propósito

Construir presencias web que no solo se vean bien, sino que trabajen activamente para el negocio del cliente: generando leads, transmitiendo confianza y funcionando impecablemente en cualquier dispositivo.

## Servicios Web

| Servicio | Descripción | Tiempo estimado |
|---|---|---|
| Landing Page | Una página enfocada en conversión | 5–7 días |
| Sitio Corporativo | Hasta 5 páginas + contacto | 10–15 días |
| Portfolio / Showcase | Presentación visual de proyectos | 7–10 días |
| Sitio con CMS | Editable por el cliente (Webflow/WP) | 15–20 días |
| Rediseño Web | Modernización de sitio existente | Según alcance |

## Stack Técnico

| Tecnología | Uso |
|---|---|
| HTML5 / CSS3 / JS | Base de todos los proyectos |
| Netlify | Deploy rápido, hosting estático |
| Figma | Mockups y wireframes |
| Webflow | Proyectos con CMS sin código |
| WordPress | Clientes que necesitan autonomía editorial |

## Proceso de Desarrollo Web

```
BRIEF → WIREFRAME → DISEÑO VISUAL → DESARROLLO → REVISIÓN → DEPLOY → ENTREGA
```

1. **Brief:** Objetivos, audiencia, referencias, contenido disponible
2. **Wireframe:** Estructura de páginas y flujo de navegación
3. **Diseño visual:** Mockup fiel en Figma (desktop + mobile)
4. **Desarrollo:** Construcción del sitio funcional
5. **Revisión:** 2 rondas de ajustes
6. **Deploy:** Publicación en hosting del cliente o Netlify
7. **Entrega:** Accesos, guía de uso y soporte inicial 15 días
