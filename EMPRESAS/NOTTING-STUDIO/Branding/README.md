# Branding — Notting Studio

> Construcción de identidades visuales sólidas, memorables y estratégicamente alineadas al negocio del cliente.

## Propósito

Diseñar sistemas de identidad visual que comuniquen quién es la marca, qué la diferencia y por qué merece ser recordada — más allá de un logo bonito.

## Servicios de Branding

| Servicio | Entregables | Tiempo estimado |
|---|---|---|
| Logo + Variantes | Primario, secundario, isotipo, versiones color/BN | 5–7 días |
| Identidad Visual Completa | Logo + paleta + tipografía + elementos gráficos | 10–15 días |
| Brandbook | Manual de identidad completo (uso correcto/incorrecto) | +5 días |
| Rebranding | Evolución o rediseño de marca existente | 15–20 días |
| Brand Strategy | Posicionamiento, arquetipo, tono de voz | 7–10 días |

## Proceso de Branding

```
BRIEF → INVESTIGACIÓN → CONCEPTO → DISEÑO → REVISIÓN → ENTREGABLES → BRANDBOOK
```

1. **Brief:** Formulario de 20 preguntas sobre el negocio, audiencia y competencia
2. **Investigación:** Análisis del mercado, referentes y anti-referentes
3. **Concepto:** 2 direcciones creativas con moodboard y justificación
4. **Diseño:** Desarrollo de la dirección aprobada
5. **Revisión:** 2 rondas de ajustes incluidas en el precio
6. **Entregables:** Archivos maestros AI, SVG, PNG, PDF en todos los tamaños
7. **Brandbook:** PDF de uso de marca con ejemplos aplicados

## Indicadores

| Indicador | Meta |
|---|---|
| Proyectos de branding por mes | ≥ 1 |
| Revisiones promedio por proyecto | ≤ 2 |
| Satisfacción post-entrega | ≥ 4.8/5 |
