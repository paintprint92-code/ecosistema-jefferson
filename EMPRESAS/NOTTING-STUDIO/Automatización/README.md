# Automatización — Notting Studio

> Diseño e implementación de flujos automáticos que eliminan tareas repetitivas y conectan el ecosistema digital del cliente.

## Propósito

Liberarle tiempo al cliente automatizando lo que no necesita intervención humana: notificaciones, respuestas, reportes, sincronización de datos, publicaciones y más — para que puedan enfocarse en lo que importa.

## Servicios de Automatización

| Servicio | Descripción | Tiempo estimado |
|---|---|---|
| Auditoría de procesos | Mapeo de qué puede automatizarse | 1–2 días |
| Flujos básicos (Zapier/Make) | Conexión entre apps sin código | 3–5 días |
| Flujos avanzados (n8n) | Automatizaciones complejas con lógica | 7–15 días |
| CRM automatizado | Pipeline de ventas con seguimiento automático | 5–10 días |
| Notificaciones automáticas | WhatsApp, email, Telegram según eventos | 3–5 días |
| Reportes automáticos | Dashboards y resúmenes generados solos | 5–7 días |

## Herramientas de Automatización

| Herramienta | Uso | Nivel |
|---|---|---|
| Make (Integromat) | Flujos visuales entre apps | Principal |
| n8n | Automatizaciones avanzadas self-hosted | Avanzado |
| Zapier | Integraciones rápidas | Básico/cliente |
| WhatsApp Business API | Mensajes automáticos | Marketing/ventas |
| Google Sheets + Apps Script | Automatización de datos y reportes | Intermedio |

## Casos de Uso Frecuentes

| Caso | Descripción |
|---|---|
| Lead → CRM | Formulario web envía datos al CRM y notifica por WhatsApp |
| Pedido → Producción | Pedido confirmado activa flujo de producción y factura |
| Contenido programado | Posts de redes sociales publicados automáticamente |
| Reporte semanal | Resumen de métricas enviado cada lunes por email |
| Seguimiento de cotizaciones | Recordatorio automático si cotización no fue respondida en 48h |

## Proceso de Automatización

```
MAPEO → DISEÑO DEL FLUJO → CONSTRUCCIÓN → PRUEBAS → DEPLOY → DOCUMENTACIÓN
```

1. **Mapeo:** Proceso actual paso a paso, identificar disparadores y acciones
2. **Diseño:** Diagrama del flujo automatizado
3. **Construcción:** Implementación en la herramienta elegida
4. **Pruebas:** Validación con datos reales o de prueba
5. **Deploy:** Activación en producción
6. **Documentación:** Manual de mantenimiento para el cliente

## Indicadores

| Indicador | Meta |
|---|---|
| Flujos activos para clientes | Registro actualizado |
| Tiempo ahorrado por cliente | ≥ 5 hs/semana promedio |
