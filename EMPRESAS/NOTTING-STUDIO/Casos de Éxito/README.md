# Casos de Éxito — Notting Studio

> Portfolio documentado de proyectos reales: resultados, proceso y evidencia del valor entregado.

## Propósito

Documentar cada proyecto notable de Notting Studio como un caso de estudio estructurado, que sirva para: (1) construir credibilidad con nuevos prospectos, (2) alimentar el portfolio web, y (3) generar contenido de marketing con sustancia real.

## Por Qué Documentar Casos de Éxito

- Un prospecto que lee un caso de éxito convierte a una tasa 3–5x mayor que uno que solo vio un portafolio visual
- El caso de éxito cuenta el ANTES, el PROCESO y el DESPUÉS — no solo el resultado estético
- Son la herramienta de ventas más poderosa para servicios creativos y tecnológicos

## Estructura de un Caso de Éxito

Cada caso se documenta en su propio archivo `[EMPRESA]-[AÑO].md` con esta estructura:

```markdown
# Caso de Éxito: [Nombre del Cliente]
**Empresa:** [sector del cliente]
**Servicio:** [qué contrató]
**Duración:** [tiempo del proyecto]
**Año:** [año]

## El Problema
Qué necesitaba el cliente. Qué no estaba funcionando.

## El Reto
Complejidades o restricciones que hubo que resolver.

## La Solución
Qué hizo Notting Studio. Proceso resumido.

## Resultados
- Métrica concreta 1
- Métrica concreta 2
- Testimonio del cliente (entre comillas)

## Materiales
- Imágenes antes/después
- Capturas del entregable
- Link al trabajo (si es público)
```

## Indicadores

| Indicador | Meta |
|---|---|
| Casos de éxito documentados | ≥ 1 nuevo por trimestre |
| Casos publicados en web | ≥ 3 al lanzar el sitio |
| Casos con testimonio escrito del cliente | ≥ 80% del total |

## Proceso para Documentar un Caso

1. Al cierre del proyecto: solicitar feedback y testimonio al cliente
2. Reunir capturas, antes/después, métricas si existen
3. Redactar el caso siguiendo la estructura de arriba
4. Revisar que el cliente apruebe antes de publicar externamente
5. Guardar en esta carpeta y subir al portfolio web
